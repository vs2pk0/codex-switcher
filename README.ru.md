Codex Switcher объединяет несколько профилей входа Codex в одном настольном приложении. Программа переключает активную учетную запись, изолированно запускает несколько экземпляров Codex, восстанавливает локальные сеансы, управляет OpenCodex и CLIProxyAPI, отслеживает квоты и показывает статистику токенов и расчетную стоимость.

## Возможности

- **Учетные записи OAuth и API Key**: добавление, редактирование, импорт, экспорт, фильтрация, сортировка, обновление и переключение между профилями.
- **Квоты и сбросы**: состояние учетной записи, срок подписки, окна квот, GPT 5.3 Codex Spark, история и расписание сбросов.
- **Управление и восстановление сеансов**: поиск проектов и сообщений, просмотр Markdown и вложений, удаление сообщений или раундов, резервное копирование, восстановление видимости и усеченной истории.
- **Независимые экземпляры Codex (macOS)**: отдельные `CODEX_HOME` и данные Electron для официального приложения; выбранный экземпляр используется при смене аккаунта, работе с сеансами, настройками и OpenCodex.
- **OpenCodex Manager**: управление прокси и версиями Engine, Web Dashboard, синхронизация моделей, совместимость с изображениями, импорт аккаунтов Switcher, журналы и возврат к нативному Codex.
- **Статистика использования**: локальные токены, кэш, распределение моделей и источников, расчетная стоимость и настраиваемые правила цен.
- **Интеграция CLIProxyAPI**: установка, обновление, запуск, настройка, версии встроенного CPA API-сервиса и привязка выбранных учетных записей.
- **Конфигурация и резервные копии**: проверка и редактирование `auth.json` и `config.toml`, автоматические копии исходных файлов, ZIP-архивы и восстановление данных.
- **Локальная конфиденциальность**: маскировка идентификаторов и учетных данных в журналах OpenCodex; данные остаются на компьютере.
- **Четыре языка интерфейса**: English, 简体中文, 繁體中文（台灣） и Русский.

## Встроенный API-сервис CPA

Раздел **API-сервис** предоставляет встроенное управление официальной средой выполнения [CLIProxyAPI (CPA)](https://github.com/router-for-me/CLIProxyAPI), поэтому отдельное ручное развертывание не требуется.

- **Быстрое управление**: определение текущей платформы, загрузка подходящего пакета, установка, запуск, остановка, обновление и сброс сервиса прямо из приложения.
- **Привязка учетных записей**: выбранные профили OAuth записываются в каталог авторизации CPA, а профили API Key — в конфигурацию вышестоящих сервисов; привязанные записи можно просматривать и удалять.
- **Настройка сервиса**: управление портом, ключом администратора, ключами доступа API, автоматическим обновлением и интервалом проверки обновлений.
- **Управление версиями**: проверка официальных выпусков, импорт доверенного локального пакета, просмотр установленных версий, переключение активной версии и удаление неактивных версий.
- **Безопасное переключение**: при смене версии работающий CPA автоматически перезапускается; если новая версия не запускается, Codex Switcher возвращает предыдущую.
- **Локальная рабочая среда**: исполняемые файлы, конфигурация, данные авторизации и кэш загрузок хранятся в `~/.codex_switcher/api-service`.

## OpenCodex Manager

Раздел **OpenCodex** интегрирует локальный прокси [OpenCodex](https://github.com/lidge-jun/opencodex) и жизненный цикл Engine в Codex Switcher.

- **Консоль сервиса**: инициализация, запуск, остановка, перезапуск, диагностика, синхронизация, проверка состояния и просмотр журналов с удаленными секретами.
- **Жизненный цикл Engine**: поиск стабильных и предварительных выпусков, установка и переключение локальных версий, удаление неактивных версий и безопасный возврат к встроенной версии.
- **Интеграция Codex**: синхронизация конфигурации и каталога моделей с выбранным экземпляром Codex либо остановка прокси и восстановление его нативной конфигурации.
- **Web Dashboard**: открытие панели OpenCodex в отдельном окне клиента или системном браузере.
- **Совместимость с изображениями**: выбор текстовых моделей, использующих дополнительную модель описания изображений, с автоматическим перезапуском и синхронизацией каталога.
- **Миграция аккаунтов и фоновая служба**: импорт совместимых OAuth-аккаунтов Switcher и регистрация OpenCodex для запуска при входе в систему.

## Установка

Загрузите актуальный установщик на странице [GitHub Releases](https://github.com/vs2pk0/codex-switcher/releases):

- **Windows**: используйте установщик `.exe` или `.msi`.
- **macOS**: откройте образ `.dmg` и переместите Codex Switcher в папку «Программы» либо запустите установщик `.pkg`.

Если macOS блокирует первый запуск, откройте **Системные настройки > Конфиденциальность и безопасность** и разрешите запуск приложения.

### macOS сообщает, что приложение повреждено и не может быть открыто

Текущий пакет для macOS не нотарифицирован, поэтому Gatekeeper может поместить приложение в карантин и сообщить о повреждении. Сначала убедитесь, что пакет загружен с официальной страницы [GitHub Releases](https://github.com/vs2pk0/codex-switcher/releases) этого проекта, затем переместите приложение в `/Applications` и выполните:

```bash
sudo xattr -rd com.apple.quarantine "/Applications/Codex Switcher.app"
```

После этого снова откройте Codex Switcher. Команда удаляет атрибут карантина только у этого приложения; не выполняйте ее для программ из ненадежных источников.

## Основной сценарий

1. Добавьте учетную запись OAuth или API Key на странице обзора.
2. Обновите учетную запись вручную, чтобы получить актуальную квоту или баланс.
3. Выберите учетную запись и переключитесь на нее. Codex Switcher обновит локальные файлы авторизации и конфигурации Codex.
4. Используйте разделы сеансов, статистики или API-сервиса для восстановления сеансов, анализа использования и управления CLIProxyAPI.

### Несколько экземпляров Codex на macOS

Откройте раздел **Экземпляры Codex** и создайте экземпляр. Можно указать Codex Home, каталог данных приложения, рабочую папку и официальное приложение; пустые пути создаются автоматически в `~/.codex_switcher/instances`. Перед запуском проверяется поддержка изолированного каталога данных. При окончательном удалении управляемый экземпляр сначала останавливается, затем удаляются его Codex Home, данные Electron, корзина сеансов и связанные резервные копии. Рабочая папка, официальное приложение, системный экземпляр и другие экземпляры защищены.

При наличии нескольких экземпляров смена аккаунта, перезапуск, синхронизация и восстановление OpenCodex сначала запрашивают цель. Сеансы можно просматривать, изменять и копировать между экземплярами; в настройках также выбирается экземпляр, чьи пути, `auth.json` и `config.toml` нужно открыть или изменить.

Полная резервная копия по умолчанию включает сеансы только официального системного экземпляра. Для дополнительных экземпляров создавайте ручные копии после выбора нужного экземпляра в разделе сеансов.

## Локальные данные и конфиденциальность

По умолчанию данные приложения хранятся в `~/.codex_switcher`:

- Учетные записи: `~/.codex_switcher/account/accounts.json`
- Сеансы: `~/.codex_switcher/session`
- Статистика использования: `~/.codex_switcher/statistics`
- Настройки: `~/.codex_switcher/data/settings.json`
- Резервные копии: `~/.codex_switcher/backup`

Активный профиль записывается в локальный каталог Codex `~/.codex`. Экспортированные файлы учетных записей могут содержать данные авторизации, поэтому храните их в безопасном месте.

## Разработка

### Требования

- Node.js 22
- Стабильная версия Rust
- [Системные зависимости Tauri 2](https://v2.tauri.app/start/prerequisites/) для вашей платформы

### Локальный запуск

```bash
npm ci
npm run tauri -- dev
```

### Проверка и сборка

```bash
npm run typecheck
npm run build
npm run tauri -- build
```

Настольное приложение создано с использованием Tauri 2, Vue 3, TypeScript, Rust, Arco Design и ECharts.
