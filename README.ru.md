Codex Switcher объединяет несколько профилей входа Codex в одном настольном приложении. Программа переключает активную учетную запись, записывает выбранные данные авторизации в локальную конфигурацию Codex, отслеживает квоты, восстанавливает сеансы и показывает статистику токенов и расчетную стоимость.

## Возможности

- **Учетные записи OAuth и API Key**: добавление, редактирование, импорт, экспорт, фильтрация, сортировка и переключение между профилями.
- **Мониторинг квот**: состояние учетной записи, срок подписки, стандартные окна квот и дополнительные окна GPT 5.3 Codex Spark.
- **Работа с сеансами**: управление, восстановление, резервное копирование и возврат локальных сеансов Codex.
- **Статистика использования**: локальные токены, кэш, распределение моделей и расчетная стоимость с настраиваемыми правилами цен.
- **Интеграция CLIProxyAPI**: установка, обновление, запуск и настройка встроенного API-сервиса, а также привязка выбранных учетных записей.
- **Конфиденциальность**: маскировка идентификаторов в интерфейсе и локальное хранение данных приложения.
- **Четыре языка интерфейса**: English, 简体中文, 繁體中文（台灣） и Русский.

## Встроенный API-сервис CPA

Раздел **API-сервис** предоставляет встроенное управление официальной средой выполнения [CLIProxyAPI (CPA)](https://github.com/router-for-me/CLIProxyAPI), поэтому отдельное ручное развертывание не требуется.

- **Быстрое управление**: определение текущей платформы, загрузка подходящего пакета, установка, запуск, остановка, обновление и сброс сервиса прямо из приложения.
- **Привязка учетных записей**: выбранные профили OAuth записываются в каталог авторизации CPA, а профили API Key — в конфигурацию вышестоящих сервисов; привязанные записи можно просматривать и удалять.
- **Настройка сервиса**: управление портом, ключом администратора, ключами доступа API, автоматическим обновлением и интервалом проверки обновлений.
- **Управление версиями**: проверка официальных выпусков, импорт доверенного локального пакета, просмотр установленных версий, переключение активной версии и удаление неактивных версий.
- **Безопасное переключение**: при смене версии работающий CPA автоматически перезапускается; если новая версия не запускается, Codex Switcher возвращает предыдущую.
- **Локальная рабочая среда**: исполняемые файлы, конфигурация, данные авторизации и кэш загрузок хранятся в `~/.codex_switcher/api-service`.

## Установка

Загрузите актуальный установщик на странице [GitHub Releases](https://github.com/vs2pk0/codex-switcher/releases):

- **Windows**: используйте установщик `.exe` или `.msi`.
- **macOS**: откройте образ `.dmg` и переместите Codex Switcher в папку «Программы» либо запустите установщик `.pkg`.

Если macOS блокирует первый запуск, откройте **Системные настройки > Конфиденциальность и безопасность** и разрешите запуск приложения.

### macOS сообщает, что приложение повреждено и не может быть открыто

Текущий пакет для macOS не нотарифицирован, поэтому Gatekeeper может поместить приложение в карантин и сообщить о повреждении. Сначала убедитесь, что пакет загружен с официальной страницы [GitHub Releases](https://github.com/vs2pk0/codex-switcher/releases) этого проекта, затем переместите приложение в `/Applications` и выполните:

```bash
sudo xattr -rd com.apple.quarantine "/Applications/Codex Switcher.app"
```

После этого снова откройте Codex Switcher. Команда удаляет атрибут карантина только у этого приложения; не выполняйте ее для программ из ненадежных источников.

## Основной сценарий

1. Добавьте учетную запись OAuth или API Key на странице обзора.
2. Обновите учетную запись вручную, чтобы получить актуальную квоту или баланс.
3. Выберите учетную запись и переключитесь на нее. Codex Switcher обновит локальные файлы авторизации и конфигурации Codex.
4. Используйте разделы сеансов, статистики или API-сервиса для восстановления сеансов, анализа использования и управления CLIProxyAPI.

## Локальные данные и конфиденциальность

По умолчанию данные приложения хранятся в `~/.codex_switcher`:

- Учетные записи: `~/.codex_switcher/account/accounts.json`
- Сеансы: `~/.codex_switcher/session`
- Статистика использования: `~/.codex_switcher/statistics`
- Настройки: `~/.codex_switcher/data/settings.json`
- Резервные копии: `~/.codex_switcher/backup`

Активный профиль записывается в локальный каталог Codex `~/.codex`. Экспортированные файлы учетных записей могут содержать данные авторизации, поэтому храните их в безопасном месте.

## Разработка

### Требования

- Node.js 22
- Стабильная версия Rust
- [Системные зависимости Tauri 2](https://v2.tauri.app/start/prerequisites/) для вашей платформы

### Локальный запуск

```bash
npm ci
npm run tauri -- dev
```

### Проверка и сборка

```bash
npm run typecheck
npm run build
npm run tauri -- build
```

Настольное приложение создано с использованием Tauri 2, Vue 3, TypeScript, Rust, Arco Design и ECharts.
