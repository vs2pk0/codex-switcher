# Codex Switcher v0.1.40

本版本修复账号与 API 模式切换后的会话图片和历史兼容性，并支持 macOS 在应用内安装更新后自动重启。

## 主要更新

- macOS 点击“在线更新”后，自动下载 DMG、校验应用标识、版本、架构和代码签名，准备完成后退出旧进程、替换应用并重新启动，无需手动拖动覆盖。
- 更新时保留旧版备份，等待新版启动确认后再清理；安装或启动失败时尝试恢复旧版，无法自动恢复时保留备份和诊断日志。安装目录不可写、从 DMG 或系统临时隔离目录运行时，会在退出前说明原因。
- 更新重启复用正常关闭时的后台服务清理，避免遗留本地 API 进程；Windows 保持现有 EXE/MSI 安装器流程。
- 账号切换前恢复会话中缺失的本地图片，包含归档会话；使用完整内容哈希区分图片，避免共享短前缀的不同图片错误复用。
- OAuth 账号、API Key、本地 API 服务和 OpenCodex 接入切换后统一同步会话 Provider、修复模型兼容性并恢复图片。服务绑定或取消绑定、恢复配置也执行相同的准备步骤。
- 修复模型兼容性变更后的分页序号和缓存投影；保护 fork、分段会话所依赖的历史内容，并将局部修复失败作为警告展示，避免成功提示遮盖问题。

## 验证情况

- 前端测试 100 项、TypeScript 类型检查和前端生产构建通过。
- Rust 回归测试 391 项通过，保留 2 项原有忽略项，跳过 2 项此前确认的本地压缩旧失败用例。
- 更新模块覆盖签名、版本、安装路径、重复操作、进程退出等待、替换失败和启动失败回滚；另已在本机单独运行真实 DMG 安装与 Launch Services 重启集成测试，通过隔离的后台测试应用验证启动参数传递。
- macOS arm64 本地应用和 DMG 构建、签名校验与镜像完整性校验通过。
- Windows 安装包由 GitHub Actions 构建，本地未进行 Windows 真机验证。

## 安装说明

旧版需要先手动安装一个包含新更新逻辑的版本，之后升级到更高版本即可在应用内自动安装并重启。macOS 安装包继续使用 ad-hoc 签名，未进行 Apple 公证。
