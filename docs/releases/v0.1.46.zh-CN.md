# Codex Switcher v0.1.46

本版本调整 Windows 在线更新的安装包启动方式，并将安装包保存到系统下载目录，方便手动查找和安装。

## Windows 在线更新

- 使用 Windows Shell 启动 EXE／MSI 安装包，并转换路径校验产生的特殊前缀，兼容包含中文和空格的路径。
- 安装包保存到系统下载目录下的 `Codex Switcher/updates/<版本号>/`，跟随系统下载文件夹设置。
- 下载完成弹窗新增“打开文件夹”，显示可选择复制的完整保存路径。
- 启动失败或用户取消授权时显示错误，保留已下载文件供直接重试。
- 成功提示改为已向系统发起打开请求，避免将请求被接受误报为安装界面已打开。

## 近期会话与更新改进

- 改进 API 与账号切换时的分段会话历史迁移，处理编辑旧消息涉及的祖先分段、分页位置和消息序号。
- 为不兼容的工具历史提供文本迁移，并在上下文超限时支持近期文本摘录恢复；原始文件保留备份。
- macOS 支持下载完成后应用内安装并自动重启，安装失败保留文件供重试。

## 验证与安装

- 本地执行前端回归测试、Rust 更新模块测试及生产构建。
- Windows 启动模块与下载路径解析通过 Windows 目标编译检查；安装界面仍需 Windows 实机验证。
- Windows 与 macOS 安装包由 GitHub Actions 构建。macOS 使用 ad-hoc 签名，未进行 Apple 公证。
