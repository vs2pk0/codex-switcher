# Codex Switcher v0.1.43

本版本新增 Codex 积分余额展示，并简化无余额账号的卡片显示。

## 主要更新

- 账号卡片在配额下方显示积分余额，紧凑和表格视图同步支持。
- 积分余额为 0、缺失或无效时隐藏整行；有余额和无限额度时正常显示。
- 复用现有额度查询响应，余额随手动及自动额度刷新更新，无需增加网络请求。
- 余额支持千分位、小数和多语言格式；悬停可查看完整数值，隐私模式同时隐藏显示值与悬停内容。
- 极小的非零积分不会因显示精度被误显示为 0；积分余额与限额重置券分别处理。
- 根据积分行是否可见调整卡片高度，保留同排卡片对齐。

## 验证情况

- 前端回归测试 108 项、TypeScript 类型检查与生产构建通过。
- 本地 Apple Silicon macOS 安装包构建通过，应用签名及 DMG 完整性校验通过。
- Windows 与 macOS 发布安装包由 GitHub Actions 构建，本地未进行 Windows 真机验证。

## 安装说明

安装后刷新账号额度即可更新积分余额。macOS 安装包继续使用 ad-hoc 签名，未进行 Apple 公证。
