# Codex Switcher v0.1.50

本版本修复大型会话预览、账号切换和一键修复时的界面卡顿与内存占用问题。

## 大型会话预览

- 读取会话内容和附件改为后台执行，预览跳过无需显示的技术记录，减少大文件解析开销。
- 大会话每页加载更少轮次，超长消息分段展开，避免一次渲染过多内容。
- 优化逆序读取长记录的缓冲方式，保留原始内容及导出、删除所需的完整读取逻辑。
- 修正异常数组记录被误认成轮次边界、导致旧格式会话预览为空的问题。

## 账号切换与会话修复

- 普通账号切换和切号会话修复在后台执行；重复切换、修复和实例操作及时提示忙碌，避免界面长时间等待实例锁。
- 模型、分页序号和图片路径修复改为逐行处理，历史链发布与失败回滚使用流式原子写入，并保留原始备份和分段历史前缀保护。
- 协议迁移只保留有效历史所需的数据；沿用既有超限摘录规则，减少完整历史及中间字符串的重复驻留。
- 消除 API 配置同步中的重复整库修复；一键修复保留健康的分页索引，仅重建发生变化或已失效的投影，手动恢复单条完整会话仍可强制重建。
- 修复旧格式会话在前置修复清理分页索引后漏掉重建的问题，按实际缺失状态补齐索引，健康会话跳过额外的全文扫描。
- 统一前端操作互斥，确认框执行时再次检查状态，避免重复任务或进度提示互相覆盖。

## 安装说明

- Windows 与 macOS 安装包由 GitHub Actions 构建。
- macOS 使用 ad-hoc 签名，未进行 Apple 公证。
