# Codex Switcher v0.1.33

本版本修复 Windows 上向 API 服务绑定账号时可能因认证目录被占用而失败的问题。

## 主要更新

### Windows API 服务账号绑定

- 绑定 OAuth 或 API Key 账号前短暂停止 API 服务，释放认证目录及配置文件的占用。
- 写入成功后自动重新启动 API 服务，无需用户手动恢复运行。
- 写入失败时回滚 API Key 配置与绑定清单，并尝试恢复 API 服务运行。
- 停止服务过程自身发生异常时也执行恢复，避免服务被意外留在停止状态。
- 绑定窗口补充短暂停服和自动重启提示，并完善英文、俄文与繁体中文翻译。

## 验证情况

- Rust 单元测试、Clippy 严格检查通过。
- 前端单元测试、类型检查与生产构建通过。
- 新增 Windows API 服务绑定顺序与异常恢复回归测试。

## 安装包

GitHub Actions 会自动构建并发布 Windows x64 和 macOS arm64 安装包。Codex 桌面多开当前仅支持 macOS。macOS 安装包使用 ad-hoc 签名，未进行 Apple 公证；首次启动时可能需要在系统设置中允许打开应用。
