# Codex Switcher v0.1.39

本版本修复 Pro 套餐倍率显示、Token 账号的桌面登录兼容性和外链打开问题，改进 JSON 下载反馈与大批量文件导入体验。

## 主要更新

- Codex 桌面多开扩展至 Windows，按实例隔离登录、配置与桌面数据。
- 改进 OpenCodex 连接信息、用户密钥和在线账号管理；管理密钥开关可安全切换本地管理页面的访问方式。
- 修复 Pro 5X 账号因 `chatgptprolite` 等套餐别名未被识别而显示为 20X 的问题；统一账号列表、账号详情与 API 服务页面的识别规则。无法确认倍率时显示 `PRO`。
- 修复仅含 access token 的账号导入后，多开实例因登录文件缺少可解析的身份字段而仍提示登录的问题；保留已有完整 OAuth 凭据。
- 统一“关于”页、GitHub 和 OpenCodex 管理页的外链打开方式。macOS 使用系统浏览器打开工具并提供浏览器兜底；Windows 使用原生 ShellExecuteW，失败时显示具体错误。
- 单个和批量 JSON 下载改为保存到系统下载目录，文件写入成功后弹窗显示文件名和完整路径。点击文件名或“打开文件夹”可打开保存目录，适配 Windows 与 macOS。
- 同名导出自动编号保存，避免覆盖已有文件；支持中文路径和 Windows 保留文件名的兼容处理。
- 一次导入超过 10 个 JSON 文件时，更新账号列表后跳过导入触发的逐账号额度、余额刷新，并提示可稍后手动刷新。10 个文件及以内保持原来的行为。

## 验证情况

- 前端测试 95 项通过，覆盖 Pro 套餐别名、导入阈值与导入失败后的状态恢复。
- Rust 账号、外链与导出文件测试 74 项通过，覆盖登录文件、中文路径、并发同名下载和写入失败。
- TypeScript 类型检查、前端生产构建及 macOS arm64 安装包构建、签名与 DMG 完整性校验通过。
- Windows 已完成代码适配，本地未进行 Windows 真机验证，安装包由 GitHub Actions 构建。

## 安装包

GitHub Actions 自动构建 Windows x64 和 macOS arm64 安装包。macOS 安装包使用本地 ad-hoc 签名，未进行 Apple 公证。
