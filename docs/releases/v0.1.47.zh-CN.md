# Codex Switcher v0.1.47

本版本修复账号切换后本地侧栏项目和会话归属丢失的问题，并完善 Pro 套餐档位显示。

## 账号切换与侧栏恢复

- 切换账号时同步本地项目、项目排序和会话归属；关闭“切换时自动修复会话”后仍保留侧栏，同时不修改会话文件和索引。
- 一键修复支持从历史账号快照恢复项目名称和归属，即使没有可用的会话文件也能恢复已保存的项目。
- 多个项目使用相同目录时，优先保留有效的原有会话归属，避免会话被分配到其他项目。
- 账号快照身份优先使用访问令牌，与桌面端的用户及工作区身份解析顺序保持一致。
- 仅同步本地项目元数据，保留目标账号自己的项目设置，不复制其他账号的云端状态、远程项目排序或登录缓存。
- 修改前独立备份原始项目状态，异常状态保留原文件并提示同步失败。

## Pro 套餐显示

- 标准 Pro 显示为 PRO 20X，明确的 Pro Lite／5X 档位优先显示为 PRO 5X。
- 支持 `pro5`、`pro20` 等数值别名；订阅刷新返回通用 Pro 时保留已识别的细分档位。

## 安装说明

- Windows 与 macOS 安装包由 GitHub Actions 构建。
- macOS 使用 ad-hoc 签名，未进行 Apple 公证。
