# Codex Switcher v0.1.26

本版本新增 macOS Codex 桌面多开管理，并完善跨实例账号、配置、OpenCodex 与会话操作；同时重点修复会话复制、回收站残留索引和恢复可见性问题。

## 主要更新

### macOS Codex 多开实例

- 新增“Codex 多开”菜单，可创建、编辑、启动、停止、重启和删除独立实例。
- 每个实例使用独立的 `CODEX_HOME` 与 Electron 数据目录，可单独指定官方 App 和启动工作区。
- 账号切换时可选择目标实例，只写入并重启所选实例，不影响其他正在运行的 Codex。
- 设置页支持按实例查看和编辑 `auth.json`、`config.toml`，OpenCodex 同步与恢复也可选择目标实例。
- 删除实例前执行严格的目录归属与重叠检查，避免误删默认实例、其他实例、工作区或官方 App。

### 跨实例会话管理

- 会话页支持切换默认实例和多开实例，分别查看项目、会话、回收站与备份。
- 支持将默认实例中的会话复制到多开实例，或在任意两个实例之间创建独立会话副本。
- 复制副本时可选择目标实例和目标工作目录，新副本与目标目录中的已有会话共存。
- 修复跨实例复制时源 rollout 无法解析、分页历史不完整及目标索引不同步的问题。
- 移入回收站和复制会话不再自动停止或重启 Codex，保持各实例当前运行状态。

### 会话回收站与可见性

- 会话移入回收站时同步更新 Codex SQLite、桌面目录和 `session_index.jsonl`，避免文件已删除但侧栏仍残留。
- 打开回收站时自动识别并清理旧版本遗留的可见索引。
- 恢复会话时重新补全对应索引、项目分组和侧栏目录信息。
- 加强会话复制、工作目录变更、生成图片恢复和分页历史修复的兼容性。

### 账号与 OpenCodex

- 多开实例共享 Switcher 账号库，但各实例保留独立的当前登录状态和 Codex 配置。
- Token 续期、API Key 默认模型修复及配置重置会作用于明确选中的实例。
- OpenCodex 同步和恢复操作会将配置写入所选实例的 `CODEX_HOME`。
