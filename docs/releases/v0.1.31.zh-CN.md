# Codex Switcher v0.1.31

本版本新增 Codex 实例的 OpenCodex 接入状态展示，并优化多开实例列表与账号切换弹窗的布局对齐。

## 主要更新

### OpenCodex 实例状态

- 自动识别哪些系统默认实例或多开实例已经接入 OpenCodex。
- 在 Codex 多开实例卡片和账号切换实例弹窗中显示 OpenCodex 标识。
- 同时兼容当前注入方式、旧版 OpenCodex provider 配置，以及 Codex 重写配置后保留的注入日志。
- 严格区分 OpenCodex 管理的路由与用户自定义 `openai_base_url`，避免误标普通代理配置。

### 布局优化

- 统一实例卡片的标题区、内容区和操作区高度，使同一行卡片保持对齐。
- 优化长实例名称和目录路径的省略显示，并可悬浮查看完整路径。
- 固定实例切换弹窗的运行状态列宽度，解决 PID 和状态标签错位、裁切问题。
- 收窄路径样式作用范围，避免影响 OpenCodex 与运行状态标签的颜色和字体。

## 验证情况

- Rust 单元测试和前端测试通过。
- TypeScript 类型检查与生产构建通过。
- `cargo clippy --all-targets -- -D warnings`、`cargo fmt --check` 和差异检查通过。

## 安装包

GitHub Actions 会自动构建并发布 Windows x64 和 macOS arm64 安装包。Codex 桌面多开当前仅支持 macOS。macOS 安装包使用 ad-hoc 签名，未进行 Apple 公证；首次启动时可能需要在系统设置中允许打开应用。
