# Codex Switcher v0.1.53

## 会话管理

- 会话列表每条会话操作栏新增快捷导出 `MD` 文档按钮，无需先打开内容预览弹窗即可一键导出完整会话及 `assets` 附件目录，并对超大体积会话采用流式零拷贝预览读取，显著降低导出耗时与内存占用。

## 性能与稳定性

- Windows 实例与进程检测改为原生 Win32/NT 快照枚举与 `WaitForSingleObject` 进程退出等待，缓存商店应用清单与多开兼容性检测结果，消除冷启动 `powershell.exe` 与 WMI 轮询导致的切号卡顿。
- 会话历史链迁移改为惰性暂存与即时释放文件句柄，未变更会话不再创建临时文件或重复刷盘；SQLite 可见性修复全面切换至进程内 `rusqlite` 单事务批处理，并在单次切号/修复流程内自动去重大库备份。
- 优化多项目侧边栏状态合并（无变更跳过重写）并加固前端事件监听卸载回收，避免长会话与频繁操作下的内存及句柄驻留。
