# Codex Switcher v0.1.30

本版本重点修复 OpenCodex 与 Codex 多开实例之间的配置隔离问题，并优化 Windows 菜单、OpenCodex 页面和会话管理的响应速度。

## 主要更新

### OpenCodex 多开实例隔离

- 多开实例的 OpenCodex 同步与恢复改为实例专用流程，只修改目标实例的 `CODEX_HOME`。
- 使用权限受限的临时 OpenCodex 配置执行同步，操作成功或失败后都会清理临时配置和令牌副本。
- OpenCodex 常规启动固定使用系统默认 Codex 实例，避免继承多开实例环境并污染主实例配置。
- 默认实例继续使用 OpenCodex 官方同步与恢复流程。

### 账号绑定

- 账号列表新增统一“绑定”菜单，可选择绑定到 API 服务或 OpenCodex。
- API 服务和 OpenCodex 未启动时会提示先启动，后端写入前会再次校验运行状态。
- 绑定 OpenCodex 账号时会按原运行方式短暂停止并恢复服务。

### 性能与 Windows 体验

- 会话列表改为流式读取摘要，避免打开会话管理时一次性加载完整大型会话文件。
- OpenCodex 状态、日志和账号扫描改为后台任务，减少界面卡顿。
- OpenCodex 日志仅按需读取文件尾部，避免大日志拖慢页面。
- Windows 执行 OpenCodex 和相关辅助命令时隐藏命令行窗口，避免切换菜单时闪现终端。

### 多语言与布局

- 补齐会话实例、备份说明和账号绑定相关文案的多语言翻译。
- 优化英文和俄文环境下账号工具栏、会话操作栏的换行与宽度布局。

## 验证情况

- Rust 单元测试、前端测试和 OpenCodex Engine 测试通过。
- TypeScript 类型检查和生产构建通过。
- `cargo clippy --all-targets -- -D warnings`、`cargo fmt --check` 和差异检查通过。

## 安装包

GitHub Actions 会自动构建并发布 Windows x64 和 macOS arm64 安装包。Codex 桌面多开当前仅支持 macOS。macOS 安装包使用 ad-hoc 签名，未进行 Apple 公证；首次启动时可能需要在系统设置中允许打开应用。
