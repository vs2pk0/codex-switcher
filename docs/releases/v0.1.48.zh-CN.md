# Codex Switcher v0.1.48

本版本支持从账号卡片手动续期登录令牌，并完善额度刷新时的订阅状态同步和失败提示。

## 手动续期登录令牌

- 在账号卡片点击 Token 状态行即可手动续期，悬停显示操作提示。
- 关闭自动续期后仍可手动操作；正在续期时显示进度并阻止重复点击。
- 有续期凭据的 OAuth 账号即使 Token 尚未过期或到期时间未知，也可立即续期；缺少凭据时提示重新登录。
- 复用现有令牌刷新和保存逻辑，更新列表及当前账号状态；续期失败时显示实际错误。

## 订阅状态同步

- 手动刷新账号额度时同步查询订阅明细，避免仅因旧到期日期尚未过去而跳过查询。
- 额度接口已确认付费套餐时，继续查询订阅明细，兼容账号信息接口仍返回旧免费状态的情况。
- 额度刷新成功、订阅查询失败时分别提示；套餐匹配时保留已知且未过期的订阅日期，套餐变化时不沿用原套餐日期。
- 订阅日期使用接口返回值，剩余时长按绝对时间计算，切换显示时区不会改变倒计时。

## 安装说明

- Windows 与 macOS 安装包由 GitHub Actions 构建。
- macOS 使用 ad-hoc 签名，未进行 Apple 公证。
