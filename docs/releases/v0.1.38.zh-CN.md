# Codex Switcher v0.1.38

本版本改进 OpenCodex 实例同步的隔离与历史保护，并增加 Engine 下载失败后的手动安装入口。

## 主要更新

- 同步前先预检目标实例；预检失败时不停止实例或重置配置，提供明确的拒绝原因。
- 同步仅更新接口和模型配置，不再自动重置基础配置、重新绑定 OAuth 或迁移会话历史。后端拒绝跨实例操作。
- OpenCodex 同步配置在写入配置后、重开实例前恢复执行一键修复（切号修复 + 恢复全部完整会话），遮罩按后端日志推进步骤；API Key 账号的「启动」改为同一套同步配置流程：停止实例 → 重置并写入该 Key 的 Provider 路由与模型目录 → 一键修复 → 成功后重新打开。
- OpenCodex、API 服务、API Key 同步及手动一键修复改为容错执行：单个损坏或无法修复的会话会记录路径与原因后跳过，继续处理其余会话；修复阶段发生其他错误也不再阻止同步流程收尾和实例重新打开。
- 修复 OpenCodex Engine 2.55+ 在模型目录已成功校验但内容无需改写时被误判为写入冲突的问题；同步刷新目录前会清理桌面主进程退出后残留的 app-server，避免旧缓存改写导致提交被拒绝，并确保重开的 Codex 加载新模型列表；若同步确实失败，会恢复同步前正在运行的 Codex 实例，避免失败后影响继续使用。
- API 账号「列表额度」：叠加与按账号两种模式下 GPT 5.3 Codex Spark 等附加窗口跟随「显示 GPT 5.3 Codex Spark 额度」设置；按账号模式的切换改为紧凑列表行（账号名 + 各窗口百分比），卡片保持固定高度，超过两行时在隐藏滚动条的列表内滚动。
- 首页账号列表新增批量删除：仅处理已勾选账号，逐个复用单账号删除清理流程；单个账号删除失败时继续处理其余账号，并汇总成功与失败数量。
- 兼容已停止实例的 WAL 数据库缺少共享内存文件时的读取，保留分页历史保护，不强制迁移。
- 恢复被历史保护拒绝时保留接入状态、Engine 和实例数据，兼容旧 Engine 缺少独立预检接口的情况。
- 版本管理新增浏览器下载和手动导入官方 .tgz 安装包，导入时校验官方完整性信息；此功能仍需联网获取版本信息及依赖。
- 调整下载与导入按钮样式，删除失败后刷新版本状态并保留确认窗口。
- 会话管理支持 Codex 0.154+ 的分段续写会话（`rollout-…-<线程 id>_<段 id>.jsonl`）：同一线程的多段文件在列表中归并为一条，大小与内容查看、搜索、Token 统计覆盖全部分段；「恢复完整会话」只校对当前写入段的分页投影，不再误把首段当作整个会话；切号会话修复与图片/可见性修复对被续写段引用的前缀逐字节保留，不再破坏 history_base 边界。

## 验证情况

- OpenCodex 测试 42 项通过（使用 Engine 2.52.0）。
- 前端测试 85 项、Engine 2.55 集成测试 19 项、实例模块 Rust 测试 13 项、TypeScript 类型检查及 macOS arm64 DMG 构建通过。

## 安装包与注意事项

GitHub Actions 自动构建 Windows x64 和 macOS arm64 安装包。macOS 安装包未进行 Apple 公证。

本版本不绕过分页历史的原生写入协调保护；受保护的恢复或卸载操作仍可能被拒绝。本机供应商别名及其他私有配置不包含在安装包中。
