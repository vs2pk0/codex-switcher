# Codex Switcher v0.1.34

本版本改进 OpenCodex 更新与版本管理、账号迁移界面，并修复引用历史会话的消耗统计告警。

## 主要更新

### OpenCodex 更新与版本管理

- 下载时显示实际字节进度，安装、校验和重启阶段显示对应状态；无法确定总大小时显示不定进度。
- 支持在服务运行中更新或切换 Engine，完成后按原运行方式恢复服务。
- 切换失败时尝试回滚原 Engine 和运行状态，恢复失败时显示明确错误。
- 支持删除未使用的本地版本，保护当前版本和后台服务仍在引用的版本。
- 下载包增加完整性校验、大小限制和超时保护。

### 账号迁移与设置界面

- 增加邮箱和账号 ID 搜索、状态和套餐筛选，以及筛选结果全选与清空选择。
- 保留筛选范围外的已选账号，并显示隐藏选择数量。
- 服务设置与账号迁移采用桌面双列半宽布局，窄窗口自动切换单列。
- 压缩列表高度和行间距，长账号信息与状态原因通过悬停查看完整内容。

### 消耗统计刷新修复

- 正确识别引用父会话历史后延迟开始的本地任务，避免把继承消耗重复计入当前会话。
- 刷新时重建统计缓存并修复可确认的历史告警，不修改原始会话文件。
- 无法确认用量归属时保留可信缓存，并展示可展开的异常详情，避免误报全部修复成功。

## 验证情况

- 前端单元测试、类型检查与生产构建通过。
- Rust 单元测试及 OpenCodex 更新、账号迁移、服务状态和实例集成测试通过。
- 浏览器验证覆盖更新进度、版本操作、搜索筛选、批量选择以及桌面和窄屏布局。

## 安装包

GitHub Actions 会自动构建并发布 Windows x64 和 macOS arm64 安装包。Codex 桌面多开当前仅支持 macOS。macOS 安装包使用 ad-hoc 签名，未进行 Apple 公证；首次启动时可能需要在系统设置中允许打开应用。
