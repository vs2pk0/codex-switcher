# Codex Switcher v0.1.29

本版本修复跨实例复制 Cursor、Claude Code 等外部工具导入的 Codex 会话时，界面误报失败并因重复操作生成多个副本的问题。

## 主要更新

### 外部导入会话复制修复

- 正确兼容外部导入会话使用的 `legacy` 历史模式，复制完成后不再误报“不是分页会话”。
- 保持分页会话的安全校验，禁止分页历史意外降级为 `legacy`。
- 调整复制流程，先校验新副本的历史模式和目标工作目录，再归档临时历史底稿。
- 校验失败时自动清理本次新建的会话文件、SQLite 记录和会话索引，避免残留不可用副本。
- 回滚前记录目标实例会话快照，确保不会删除复制操作前已经存在的会话。

## 安装包

GitHub Actions 会自动构建并发布 Windows x64 和 macOS arm64 安装包。Codex 桌面多开当前仅支持 macOS。macOS 安装包使用 ad-hoc 签名，未进行 Apple 公证；首次启动时可能需要在系统设置中允许打开应用。
