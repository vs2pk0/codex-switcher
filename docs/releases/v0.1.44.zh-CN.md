# Codex Switcher v0.1.44

本版本修复订阅状态更新不及时的问题，并汇总近期的时区、API 设置、会话导出与消耗看板更新。

## 订阅状态修复

- 手动刷新账号额度时同步核验订阅状态；后台定期复查，避免未来到期日期阻止刷新。
- 优先使用额度接口返回的当前套餐；未返回套餐时，辅助识别仅有月度额度窗口的免费账号。
- 已失效订阅清除旧到期日期与 Pro 标识，卡片、紧凑列表、表格及筛选保持一致。
- 保留 Pro 5X／20X 明细，避免通用 Pro 套餐覆盖已识别的档位。
- 续费后不再沿用旧的过期日期；已核验状态在 Token 续期、导出与重新导入后保持一致。
- 按当前工作区查询额度与订阅，避免误用同一用户其他工作区的套餐。

## 功能与体验更新

- 兼容 Windows 商店版 Codex 启动，修复切换账号后直接启动被拒绝访问的问题。
- 新增全局时区设置，默认跟随系统；日期显示、筛选和统计统一使用选定时区。
- API 账号支持上下文压缩阈值、推理强度、联网搜索兼容与 Fast 设置，切换时自动应用。
- 会话 PDF、Markdown 导出统一放入下载目录下的 `Codex Account Switcher` 文件夹。
- 重构消耗看板、请求日志、来源汇总与模型用量，支持 Token 单位切换和速度估算。
- 新增预置模型价格、定价管理和 models.dev 导入与同步，调整看板布局和图标。

## 验证情况

- 前端回归测试、Rust 单元测试、类型检查与生产构建通过。
- 本地 Apple Silicon macOS 安装包构建通过，应用签名及 DMG 完整性校验通过。
- Windows 与 macOS 发布安装包由 GitHub Actions 构建，本地未进行 Windows 真机验证。

## 安装说明

安装后手动刷新账号额度即可重新核验订阅状态。macOS 安装包继续使用 ad-hoc 签名，未进行 Apple 公证。
