 # Codex Switcher v0.1.22

本版本围绕账号可见性、OpenCodex 集成和桌面发布流程进行了完善，重点解决恢复会话后列表状态不一致、账号选择范围不明确以及多平台分发的问题。

## 主要更新

### 账号隐身模式

- 在账号编辑窗口增加“隐身模式”开关。
- 隐身账号仍保留在 Codex Switcher 主账号列表中，但不会出现在 API 服务和 OpenCodex 的账号选择列表中。
- API 服务绑定接口增加后端校验，避免通过绕过前端的方式绑定隐身账号。
- 将已经绑定到 API 服务的账号改为隐身时，应用会自动移除对应的 API 服务绑定；如果移除失败，会给出明确提示。
- JSON 编辑账号时，如果没有明确提供隐身字段，会保留账号原有的隐身状态。

### 账号状态标识

- `隐` 表示账号处于隐身模式。
- `A` 表示账号已加入 API 服务。
- `O` 表示账号已导入 OpenCodex。
- 三种标识改为独立状态轨道，不再挤压或遮挡长邮箱、账号标题、额度和操作按钮。
- 卡片、紧凑列表和表格视图分别适配了状态轨道布局，并保留悬停说明。

### OpenCodex 集成

- OpenCodex 默认端口统一为 `15800`，并兼容旧配置迁移。
- 增加 OpenCodex 账号扫描、导入、版本管理、日志、设置和后台服务管理。
- OpenCodex 后台服务支持注册与取消注册，并显示真实系统服务状态。
- 隐身账号在 OpenCodex 扫描中会被标记为不可导入。

### 会话与恢复稳定性

- 优化恢复会话后的列表可见性修复流程。
- 改善历史会话图片恢复和本地生成图片重建。
- 增强 API Key 模式下 remote compact 的兼容处理。
