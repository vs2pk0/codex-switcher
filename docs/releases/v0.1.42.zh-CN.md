# Codex Switcher v0.1.42

本版本新增会话 Markdown 导出，优化大会话 PDF 导出，并提供账号切换行为开关与新版设置布局。

## 主要更新

- 会话内容支持“导出 MD”，按时间顺序导出完整会话；图片和文件保存到同级 assets 目录，以 Markdown 相对路径引用，便于移动和分享。
- 导出完成后显示保存位置，可点击文件名或“打开文件夹”；无法读取的附件会在文档和完成提示中注明。重复导出使用独立目录，避免覆盖已有文档。
- 保留原始 Markdown 正文及代码示例，复制附件时处理中文、特殊字符和长标题；图片源文件失效时可从会话内嵌图片恢复并更新正文链接。
- PDF 导出增加后台 Worker，执行分页、图片编码和 PDF 序列化；合批截图并对超长消息分段，减少主线程负担，兼容环境保留原有导出路径。
- 设置增加“切换时重置默认配置”和“切换时自动修复会话”，默认关闭；账号与 API 配置切换遵循这些开关，需要时仍可手动修复。
- 重新组织设置页，将账号切换、额度刷新、外观和本地数据分区显示；同排卡片高度对齐，目录支持展开和打开原始位置。

## 安装说明

分享 Markdown 导出结果时，请将 .md 文件和 assets 附件目录一起移动或分享。附件保持原始大小。macOS 安装包继续使用 ad-hoc 签名，未进行 Apple 公证。
