# Codex Switcher v0.1.32

本版本增强跨实例会话恢复能力，并进一步隔离系统默认实例与多开实例的 OpenCodex 配置。

## 主要更新

### 跨实例会话恢复

- “恢复完整会话”会清理无法在目标实例解密的远端推理与压缩记录。
- 将目标会话的模型统一恢复为 `gpt-5.5`，并同步修复 SQLite 元数据中的模型与 Provider。
- 对超过上下文限制的会话生成有界的本地压缩快照，保留可读摘要和近期用户/助手消息，避免远端压缩再次因上下文过大失败。
- 原始完整历史仍保留在本地会话文件中供界面展示，并在修复前自动备份。
- 重建选中会话的分页历史投影，确保单个会话修复能够覆盖跨实例复制后的残留索引。

### OpenCodex 实例隔离

- 多开实例同步 OpenCodex 前，持久关闭系统默认实例的 OpenCodex 集成开关并恢复原生 Codex 路由。
- 默认实例恢复与多开实例注入分别在独立辅助进程中执行，避免运行时缓存混用两个 `CODEX_HOME`。
- 同步或恢复结束后立即刷新实例状态，保证 OpenCodex 接入标识与实际配置一致。

## 安装包

GitHub Actions 会自动构建并发布 Windows x64 和 macOS arm64 安装包。Codex 桌面多开当前仅支持 macOS。macOS 安装包使用 ad-hoc 签名，未进行 Apple 公证；首次启动时可能需要在系统设置中允许打开应用。
