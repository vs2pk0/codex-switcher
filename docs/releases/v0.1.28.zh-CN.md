# Codex Switcher v0.1.28

本版本修复 Windows 默认 Codex 实例的启停与重启流程，并完善会话历史、图片恢复和新增功能的多语言支持。Codex 桌面多开继续仅在 macOS 开放。

## 主要更新

### Windows 默认实例修复

- 恢复 Windows 默认 Codex 进程的检测、关闭、启动与重启能力。
- 兼容 Microsoft Store、AppX、本地安装目录、开始菜单快捷方式和 `PATH` 中的 Codex。
- 修复账号切换、会话恢复、可见性修复等操作在 Windows 完成文件修改后无法重新启动 Codex 的问题。
- Windows 隐藏“Codex 多开”入口，后端同时拒绝创建或启动多开实例，避免误用尚未开放的功能。

### 会话历史与图片恢复

- 新增完整会话修复入口，重建缺失的分页历史与桌面可见性数据。
- 修复会话历史存在但恢复后仍显示不完整的问题。
- 修复会话中的本地图片和生成图片在恢复后无法显示的问题。

### 多语言与文档

- 完善设置、Codex 多开和 OpenCodex 管理页面的英文、俄文、繁体中文翻译。
- 更新中英文、俄文和繁体中文 README，加入 OpenCodex、多开、会话修复等核心功能截图。

## 验证情况

- Rust 单元测试：279 项通过。
- 前端测试：32 项通过。
- TypeScript 类型检查和生产构建通过。
- `cargo clippy --all-targets -- -D warnings`、`cargo fmt --check` 和差异检查通过。

## 安装包

GitHub Actions 会自动构建并发布 Windows x64 和 macOS arm64 安装包。Codex 桌面多开当前仅支持 macOS。macOS 安装包使用 ad-hoc 签名，未进行 Apple 公证；首次启动时可能需要在系统设置中允许打开应用。
