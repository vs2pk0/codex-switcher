# Codex Switcher v0.1.49

本版本修复同一邮箱重复添加 OAuth 账号的问题，并完善重复记录合并后的信息保留和账号引用兼容。

## 同邮箱账号合并

- 本机账号导入、OAuth 登录、Token JSON 与文件导入统一按邮箱匹配，忽略大小写和首尾空格，并沿用已有账号的本地 ID。
- 昵称、标签和电话逐项保留非空值；新导入记录提供非空值时优先使用新值。
- 加载账号列表时自动合并旧的同邮箱重复记录，备注信息按添加时间取最新非空值，登录凭据保留最近更新的版本。
- API Key 账号和缺少真实邮箱的 Token 占位记录不会按邮箱误合并；冲突的账号 ID 会拒绝导入。

## 信息与引用保留

- 合并时保留可用的续期凭据、隐身设置和额度缓存，避免较旧的订阅查询覆盖较新的状态。
- 同步当前账号、多开实例和 OAuth 绑定引用，并保留被合并 ID 的对应关系，兼容置顶、自定义顺序、预约重置和 API 服务绑定。
- 批量导入返回实际保存的账号，多文件重复导入只统计和刷新一次；JSON 编辑阻止创建同邮箱重复账号。
- 适配备份及恢复流程的账号锁，避免自动合并时重复获取锁。

## 安装说明

- Windows 与 macOS 安装包由 GitHub Actions 构建。
- macOS 使用 ad-hoc 签名，未进行 Apple 公证。
