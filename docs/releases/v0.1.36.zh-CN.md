# Codex Switcher v0.1.36

本版本修复使用统计漏算 Codex 多代理子线程用量的问题，调整导航结构（侧边栏新增推送入口、移除页面顶部大标题），账号总览支持按窗口宽度自适应每行数量，并补齐 OpenCodex 数据传输页的多语言。

## 主要更新

### 使用统计

- 修复 Codex 多代理（子代理线程）的 token 用量被整体丢弃的问题：这类 rollout 复制了父线程历史、自身计数器从零开始，与父 rollout 没有公共回放前缀，旧版本会保守地忽略全部事件，导致统计偏少（Windows 用户反馈集中于此）。现在会识别独立计数器并把事件归属给子线程；父文件已丢失时仅对 session_meta 明确标注子代理的文件放行。
- 统计缓存版本升级，下次打开统计页自动重建，无需手动刷新。
- 统计页不再展示「会话统计项需要注意」告警横幅，未能自动归属的项只记录到控制台。

### 导航与页面

- 侧边栏「重置记录」改为「推送」入口，直接进入推送设置；「重置记录」移至设置页「推送与重置」卡片。
- 移除各页面顶部的 "Codex Switcher" 大标题与副标题，账号总览仅保留状态行与操作按钮。
- 侧边栏收起时 logo、菜单图标与展开按钮居中，展开时底部按钮居中，应用名字号调小。
- 修复推送规则「结果排序」下拉点击后立即关闭无法选择的问题。

### 账号总览

- 「每行账号数」新增「自适应」并作为默认值：以 1800px 窗口显示 5 个为基准，按窗口宽度自动计算（最少 3 列、最多 8 列），拖动窗口实时生效；仍可选择固定 3 / 4 / 5 个。

### 多语言

- OpenCodex「数据传输」页全部文案接入多语言，并补齐版本管理页遗漏的英文 / 俄文词条。

## 验证情况

- 前端类型检查与单元测试通过（含新增的自适应列数、导航结构、统计告警处理测试）。
- Rust 单元测试通过（含子代理线程用量归属的正例与反例测试），clippy 与 rustfmt 检查通过。

## 安装包

GitHub Actions 会自动构建并发布 Windows x64 和 macOS arm64 安装包。Codex 桌面多开当前仅支持 macOS。macOS 安装包使用 ad-hoc 签名，未进行 Apple 公证；首次启动时可能需要在系统设置中允许打开应用。
