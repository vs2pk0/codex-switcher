# Codex Switcher v0.1.27

本版本修复 macOS 默认 Codex 实例的启动与进程识别逻辑，使默认实例和多开实例保持正确隔离。

## 主要更新

- 默认实例改为直接启动 Codex 可执行文件，并继续注入对应的 `CODEX_HOME` 和 Electron 数据目录环境变量。
- 默认实例启动时不再传入 `--user-data-dir`，多开实例仍使用各自独立的数据目录。
- 进程检测同时兼容未显式指定数据目录的默认实例和旧版显式指定默认数据目录的进程。
- 新增默认实例与多开实例进程匹配测试，避免不同实例互相误判。

## 安装包

GitHub Actions 会自动构建并发布 Windows x64 和 macOS arm64 安装包。macOS 安装包使用 ad-hoc 签名，未进行 Apple 公证；首次启动时可能需要在系统设置中允许打开应用。
