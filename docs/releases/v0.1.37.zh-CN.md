# Codex Switcher v0.1.37

本版本为 OpenCodex 增加 Codex「Image Gen」图片生成上游设置，会话页新增会话编辑备份的按实例管理与清理、回收站永久删除，并修复关闭 OpenCodex 管理子窗口后 API 服务无法再开启的问题。

## 主要更新

### OpenCodex 图片生成

- 「图片模型」页新增「图片生成上游」设置：Codex 内置的 Image Gen 工具会直接请求 `/v1/images/generations`，现在可以选择任意已配置 API Key、兼容 OpenAI 接口的提供方承接该请求。保存时自动创建 `{提供方}-images` 镜像提供方，只承接生图请求、不会向聊天模型列表新增条目；恢复默认则回到 OpenCodex 内置的 ChatGPT 转发 / OpenAI API Key 路径。
- 新增图片生成超时设置（5–300 秒）。
- 新增「最近生图请求」列表，显示最近 5 次生图请求的模型、状态、耗时与错误码；最近一次被上游拒绝时给出提示，便于区分是本地链路问题还是提供方 `/v1/images` 接口不可用。
- 图片模型页布局重排：生图设置与图片描述器并排展示，窄窗口自动单列；修复提供方下拉选中后文本拼接显示的问题。

### 会话管理

- 统计卡片行新增「编辑备份」卡片：删除轮次、删除消息、修改工作目录与一键修复切号会话前保留的原会话备份此前不会自动清理，现在可按实例查看数量与占用，并在弹窗中按条勾选删除、清空当前实例、清理无法归属（原会话已彻底删除）的备份或清空全部实例。卡片上会同时提示全部实例合计占用。
- 回收站新增「永久删除」：勾选后经二次确认即可彻底删除回收站中的会话文件及其元数据，只允许删除位于回收站目录内的文件。

### 修复

- 修复关闭 OpenCodex Web 管理子窗口后，API 服务提示「应用正在退出，已取消 API 服务操作」无法再开启的问题：退出清理逻辑现在只在主窗口销毁时触发。

## 验证情况

- 前端类型检查与单元测试通过（含图片生成设置、编辑备份管理、回收站永久删除的结构测试）。
- Rust 单元测试通过（含图片镜像提供方、备份归属统计、回收站永久删除的测试），clippy 与 rustfmt 检查通过。

## 安装包

GitHub Actions 会自动构建并发布 Windows x64 和 macOS arm64 安装包。Codex 桌面多开当前仅支持 macOS。macOS 安装包使用 ad-hoc 签名，未进行 Apple 公证；首次启动时可能需要在系统设置中允许打开应用。
