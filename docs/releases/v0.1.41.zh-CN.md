# Codex Switcher v0.1.41

本版本修复“恢复完整会话”失败和分页历史显示不完整的问题，恢复时保留会话原有模型及上下文。

## 主要更新

- 修复 macOS 下 AppTimeZone 等注入库与系统工具架构不兼容，导致 SQLite、进程检测、浏览器及文件夹打开失败的问题；仅为相关子进程清理注入设置。
- 修复前先检查 SQLite 工具与状态数据库，避免工具不可用时先修改会话文件、随后报错，留下未完成的恢复结果。
- 清理过期分页索引后，通过 Codex 原生运行时重新载入本地历史并验证索引已生成，再重新打开目标实例；恢复操作放到后台执行，避免界面卡住。
- “恢复完整会话”保留原有模型、加密推理和压缩上下文，不再强制改为旧模型或删除这些内容；继续保护 fork、分段会话依赖的历史前缀。
- 支持新版 macOS Codex 应用内嵌 CLI 路径；一键修复、备份恢复及接入同步统一使用分页历史重建流程，重建未完成时显示警告。

## 验证情况

- Rust 回归测试 397 项通过，4 项环境相关测试按定义忽略，本次未额外过滤用例。
- 前端测试 100 项、TypeScript 类型检查和前端生产构建通过。
- 单独运行真实会话隔离副本的恢复集成测试，验证原有记录保留、过期分页索引重建及完整历史读取。
- Windows 与 macOS 发布安装包由 GitHub Actions 构建；本地未进行 Windows 真机验证。

## 安装说明

安装后，对仍显示不完整的会话点击“恢复完整会话”，重新生成其分页历史索引。macOS 安装包继续使用 ad-hoc 签名，未进行 Apple 公证。
